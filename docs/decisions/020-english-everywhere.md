# ADR-020: Everything in the repository is written in English

Date: 2026-09-19 · Status: Accepted

## Context

The repository is public and intended for an international audience. Mixed-language code and docs read poorly and confuse tooling conventions.

## Decision

All committed content — code, identifiers, comments, commit messages, README, runbooks, ADRs, and the PRD itself — is in English, down to the smallest comment. Conversation with the operator may remain in any language.

## Consequences

- The original Indonesian PRD was translated rather than kept alongside.
